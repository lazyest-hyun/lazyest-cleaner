# UI 정렬 점검

2026-09-07 기준 소스 UI를 예시 데이터로 점검했습니다. 창을 표시하거나 설치된 앱을 실행하지 않았으며, 실제 스캔·삭제·권한 변경은 수행하지 않았습니다.

## 화면 범위

| 같은 단계의 화면 | 세부 화면 | 점검 방법 |
| --- | --- | --- |
| 개요 | 저장 공간 대기, 표시 완료, 권한 미허용, 스캔 중 | 실제 OverviewView 렌더링 |
| 빠른 정리 | 빠른 정리 | 실제 CleanupDetailView 렌더링 |
| 앱 | 설치 앱, 시스템 앱, 잔여 데이터 | 같은 헤더와 표 렌더링 |
| 파일 | 대용량, 오래된 파일, 중복, 다운로드, 데스크톱 영상, 사용자 지정 | 같은 헤더와 표 또는 위치 없음 상태 렌더링 |
| 앱 데이터 | 캐시, 브라우저, 로그, 휴지통 | 같은 헤더와 표 렌더링 |
| 개발 | 개발 도구, Docker | 같은 헤더와 표 렌더링 |
| 기록 | 비어 있음, 완료 및 일부 실패 | 실제 HistoryView 렌더링 |
| 설정 | 일반, 스캔 위치, 보호 | 실제 SettingsView 렌더링 |
| 공통 상태 및 대화상자 | 스캔 전, 결과 없음, 검색 결과 없음, 스캔 중, 권한 오류, 시간 초과, 사용 불가, 실패, 일반 및 강화 확인 | 실제 본문과 ConfirmationSheet 렌더링 |

총 57개 화면·상태·크기 조합을 출력했습니다. 기본 화면은 1180 × 760pt와 최소 크기 860 × 620pt, 확인 대화상자는 540 × 430pt입니다. 16개 정리 분류와 설정 3개 탭 모두 포함합니다. 사용자 지정 분류는 위치가 없는 상태를 사용했습니다.

## 수정한 문제

- 사이드바, 분류 제목, 기록 및 보호 목록에 20pt 아이콘 칸을 적용해 심벌 폭에 따른 텍스트 이동을 없앴습니다.
- 정리 분류 제목을 같은 헤더에 배치하고 전환 버튼을 분리했습니다. 단일 분류에는 불필요한 비활성 선택기를 표시하지 않습니다.
- 설정 탭을 고정 프레임의 왼쪽에 맞췄습니다. 일반 설정의 제목은 왼쪽, 스위치와 값은 오른쪽에 맞췄습니다. 위치·보호 목록의 추가 버튼 바는 같은 52pt 높이와 16pt 여백을 사용합니다.
- 최소 창 크기에서 기록 표의 결과 열이 잘리는 문제를 수정했습니다. 긴 날짜와 작업명은 툴팁으로 확인할 수 있습니다.
- 개요의 저장 공간 수치 칸과 권한 상태 칸을 고정했습니다. 데이터·권한 확인 결과가 도착해도 아래 빠른 정리와 영역 목록이 이동하지 않습니다.
- 스캔 중에도 빈 상태의 버튼 공간을 유지하고, 진행 표시를 3pt 영역 안에 잘라 제목과 본문 경계가 움직이지 않도록 했습니다.

## 의도적으로 유지한 구조

모든 주 화면은 ContentView의 동일한 navigationTitle을 사용합니다. 개요의 저장 공간 블록(132pt), 정리 화면의 도구 헤더(84pt), 설정의 공통 탭 바는 목적이 달라 내부 높이를 같게 만들지 않았습니다. 기록은 표가 바로 시작합니다. 설정의 일반 탭에는 목록 추가 버튼이 없으며, 나머지 두 탭은 동일한 하단 바를 사용합니다.

## 검증과 한계

Swift 빌드, 변경 파일의 swift-format 검사, git diff --check가 통과했습니다. 작은 창에서 개요, 정리 계열, 기록, 설정 3개 탭, 빈 상태와 오류 상태, 확인 대화상자를 시각적으로 확인했습니다. README 이미지도 같은 렌더러로 갱신했습니다.

렌더러는 실제 본문을 사용하지만 사이드바와 상단 제목은 정적인 문서용 틀입니다. 네이티브 사이드바의 반투명 합성, 툴바·검색창의 실제 창 배치, 메뉴 펼침, 키보드·VoiceOver, 다크 모드, 다른 macOS 버전, 실제 전환 애니메이션은 이번 점검에서 실행하지 않았습니다. 본문 그림이 정상인 것이 실제 스캔·삭제 기능의 검증을 의미하지는 않습니다.

`ui-layout-contracts.json`은 소스의 레이아웃 제약을 기록합니다. 실제 네이티브 창에서 측정한 좌표가 아닙니다. 예시 파일 및 보호 경로는 `/Users/demo`를 사용합니다.

재현 명령:

```sh
swift build --disable-sandbox
.build/debug/LazyestCleaner --export-ui-audit /tmp/lazyest-cleaner-ui-audit
.build/debug/LazyestCleaner --export-preview docs/images
```

## 배포본과 후속 렌더러 보정

1.1.1의 실제 앱 UI 변경은 서명·공증된 DMG로 설치했다. 이후 문서 렌더러의 빈 기록 화면 헤더를 48pt로 고정하는 보정을 소스에 추가했다. 57개를 다시 그렸을 때 바뀐 것은 빈 기록 화면 2개이며 실제 앱 본문과 README 이미지 3개는 동일했다. 이 렌더러 전용 후속 보정의 재공증은 기존 `lazyest-notary` 인증 프로필 접근 실패로 완료하지 못했다. 따라서 설치 DMG는 실제 UI 수정본이지만 마지막 렌더러 보정까지 포함한 최신 소스 빌드는 아니다.
